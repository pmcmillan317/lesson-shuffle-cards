How to use it

  1. 1Print the planner for yourself. Fill in your topic, subtopics and guiding questions.
  2. 2Type the subtopics into the class slides so each talk gets its own two-minute slide.
  3. 3Print the takeaway sheet, one per student. Listeners jot one takeaway per talk.
  4. 4Use the takeaway sheets for the closing quiz. Reteach the question most students missed.

Ignite Bites Planner

You only need the topic. List the subtopics here, then type them into the class slides.

Directions
  1. 1Write your topic. Split it into one subtopic for each pair of students.
  2. 2Give each subtopic one guiding question. Check that the subtopics do not overlap and that together they cover the topic.
  3. 3Type the subtopics into the class slides (Class slides, then Set up). Each talk gets its own two-minute slide.
  4. 4Make pairs fast: count off from 1 to the number of subtopics. Same number makes a pair, and that number is their subtopic. Odd one out? Make one group of three.
