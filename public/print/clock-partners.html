Clock Partners

Set up 12 ready-made partners once, then call a time to rotate fast.

Name Date

How to fill it in (about 10 minutes, once)

  1. Stand up with this sheet and a pencil.
  2. Find a classmate with the same hour open. Write each other’s names on that hour.
  3. Each name can appear only once on your clock.
  4. Fill as many hours as you can. Ask your teacher for help with any blanks.
