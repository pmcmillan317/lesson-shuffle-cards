How to use it

  1. 1Print one per class, or slide it into a clipboard sleeve.
  2. 2Write names in before class so you can check fast.
  3. 3Walk the room early in practice. Check each student's first problem. Start with students who usually need help.
  4. 4Pull anyone marked stuck to a side table for a quick reteach while the rest keep going.
