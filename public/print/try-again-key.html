Try Again Answer Key and Hint SheetAssessment & Retrieval · For Try Again

How to use it

  1. 1Print one sheet for each question set, and one copy for each pair.
  2. 2Fill in a row for each question: the answer and one hint. A hint names a first step, not the answer.
  3. 3Give the sheet to the checker. The solver gets only the questions.
  4. 4Checkers mark each miss. After two misses on a question, they read its hint.

Try Again Answer Key and Hint Sheet

Checker, this sheet is yours. Write one row per question. The solver never sees it.

Set Solver Checker
Checker rules
  1. 1Say only “yes” or “try again.” Never the answer.
  2. 2After two misses on a question, read its hint.
  3. 3When every answer is right, swap roles.

Example: Question 2x + 5 = 17. Answer x = 6. Hint: “Undo the + 5 first.” A hint names a first step. It does not give the answer.
