How to use it

  1. 1Print one page for every four students, on cardstock if you can. Cut along the dashed lines.
  2. 2Each student takes a card and writes one question from the unit in the top box.
  3. 3Turn the card upside down and write the answer in the bottom box, so it reads right side up after folding.
  4. 4Fold on the dotted line. The question shows on one side and the answer on the other. Spot-check a few for accuracy, then start the quizzing.
