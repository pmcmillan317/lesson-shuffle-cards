The move

Break the lesson into roughly 10-minute blocks and change what students are doing at each switch.

Before class: Plan the blocks

  1. Plan the blocksBefore classExample: teach (10), partner talk (10), practice (10), check (5).
  2. Post the plan30 secondsWrite the blocks on the board.“Here’s our game plan. Watch the timer.”
  3. Run each blockAbout 10 minutesStart the timer each time.
  4. Shift30 seconds“Shift! Stand, stretch, and move to the next block.”A quick physical reset helps.
  5. Run the check block (5 minutes)5 minutesOne question on paper or boards.

Why it works

Attention doesn’t drop off at one set minute. It drifts in and out in short cycles all lesson long. Research with classroom clickers found fewer of these lapses during active segments, like questions and demonstrations, and right after them. Switching formats regularly builds those active moments in.

Watch out for

  • Blocks that are all you talking: at least half should be students working.
  • Messy transitions: pair this card with Flow Finder.
  • Rigid timing: 8–12 minutes is fine. The switch matters more than the exact number.

Level up

  • Students choose the order of the blocks.
  • Add a 60-second recall question at every shift.

Make it work for everyone

  • Multilingual learners: use the same block icons every day so the plan is easy to read.
  • IEP and 504 supports: the posted plan helps students who need predictability.
  • Early finishers: keep a “bonus block” task ready.

Tech upgrades

Free tools that change the task, not just the medium.

  • AugmentClassroomscreenStack the timer with the Work symbols widget so students always see the block and the expected voice level.
  • ModifyHyperDoc in Google DocsLink each block’s task in one doc so students move through blocks on their own once they know the routine.

AI prompts

Copy, fill in the [brackets] and paste into Gemini, ChatGPT or Claude. Leave out student names and personal details.

Make the materials

I teach [grade] [subject]. We are working on [topic]. Plan a [length]-minute lesson on [topic] in blocks of about 10 minutes, each with a different student activity (listen, talk, write, move, practice, check). Give each block a name, what students do and a 30-second physical reset between blocks. Before you finish: No two blocks in a row should use the same activity type. Write at a level my students can read. If anything above is unclear, ask me up to 3 questions before you start.

Build a classroom app

Build a single-file web app (HTML, CSS and JavaScript in one file) for my [grade] class. Make a block-schedule display: I enter block names and minutes; it shows the current block in big text with a countdown, a progress bar of the whole lesson, and a "Shift!" screen between blocks. Requirements: no sign-in, no outside services, nothing saved except in this browser; large text that reads on a projector; works on a Chromebook; every control reachable by keyboard; clean, friendly design. Show me the working app, then tell me how to change the content.

Works in Gemini Canvas, ChatGPT Canvas or Claude. Each gives you a working app you can preview, tweak by asking for changes and share by link.
