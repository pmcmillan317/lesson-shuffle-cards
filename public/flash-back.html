The move

Twice a week, open class with three recall questions: one from last week, one from last month and one from last unit.

Step by step

Before class: Post three questions

  1. Post three questionsBefore classLabel them: Last week. Last month. Last unit.
  2. Answer from memory2 minutes“No notes. Answer all three. Guess if you’re not sure.”
  3. Reveal1–2 minutesShow answers. Students check and correct in a different color.
  4. Quick poll30 seconds“Hands up if you got the last-unit one.”Note which one the class forgot.

See how it works

See it in action

Last week: a spelling pattern. Last month: a shape’s properties. Last unit: a story’s main character.

Last week: a vocabulary word. Last month: a map location. Last unit: a cause of an event.

Last week: a formula. Last month: a graph type. Last unit: a key definition.

Watch out for

  • Only asking yesterday’s content: the older questions are the point.
  • Grading it: keep it low stakes.
  • Questions too long: one-line answers.

Level up

  • Students write the flashback questions for each other.
  • Add a fourth question from last semester.

Why it works

We forget fast when a unit moves on. Recalling older material at spaced intervals interrupts that forgetting and makes memories last much longer than cramming. Mixing old and new also shows students the course connects.

Make it work for everyone

  • Multilingual learners: keep vocabulary in questions familiar; allow sketches.
  • IEP and 504 supports: offer multiple-choice versions.
  • Early finishers: explain how two of the answers connect.

Tech option

A three-question quiz in any quiz tool, ungraded.
