Ten-Po Shift block timer

Run the whole period on the projector: one block at a time, a countdown, and a clear Shift between blocks.

Block 1 of 4

    Learn it

    10:00

      Keys: Space start or pause · N next block · P plan · + - add or remove a minute · R restart

      Plan your blocks

      Four blocks of about ten minutes, each a different way to work. Change any of it. Changes apply right away, even mid-lesson.

        Your plan is saved in this browser only. Nothing you type leaves this device, and there is no sign-in. A setup link keeps the plan inside the link itself.

        How to use it

        1. Before class, plan the blocks: about ten minutes each, a different way to work in each. Open Plan your blocks to change them.
        2. Post the plan on the board and say: "Here's our game plan. Four parts, about ten minutes each. Watch the timer."
        3. Press Start at the beginning of each block. The countdown and the progress bar stay on the projector.
        4. When the timer ends, the Shift screen shows what is next. Switch seats, partners or materials, then press Start next block.
