The move

Give everyone think time, then pull a name stick at random so anyone could be asked.

Step by step

Step timing

  1. 2Ask the question5 seconds
  2. 3Think time5–10 seconds
  3. 4Pull a stick2 seconds

Before class: Set the norm

  1. Set the normOnce“In here, everyone thinks. I’ll pull names at random, and you can always phone a friend.”
  2. Ask the question5 secondsNo hands.
  3. Think time5–10 secondsEveryone jots a one-word answer or whispers it to a partner, so every student commits before you pull.“Think. Write your answer down. Everyone have one ready.”
  4. Pull a stick2 secondsRead the name.
  5. SupportAs neededIf they’re stuck: “Want to phone a friend, or hear it again?” Come back to them after.
  6. Return the stickPut it back so anyone can be called again.

Why it works

When only volunteers answer, the same few students do the thinking. If anyone might be called, everyone prepares an answer. In one study, regular cold-calling increased how often students volunteered and made them more comfortable speaking.

Watch out for

  • “Gotcha” questions: use it to include, not to catch.
  • No think time: always pause before pulling.
  • Taking sticks out after they’re used: students stop listening once called.

Level up

  • Pull two sticks, and the second student has to build on the first.
  • Pair it with Boards Up! so everyone answers first, then you pull a name to explain.

Make it work for everyone

  • Multilingual learners: let them rehearse with a partner before you pull.
  • IEP and 504 supports: pre-warn a student privately before a question you’ll ask them.

Tech option

Any random name picker on the board works the same way.

Evidence

Moderate

Dallimore, E. J., Hertenstein, J. H., & Platt, M. B. (2013). Impact of cold-calling on student voluntary participation. Journal of Management Education, 37(3), 305–341. Cold-calling increased voluntary participation and reduced discomfort (college students).

Wiliam, D. (2011). Embedded Formative Assessment. Solution Tree Press. Recommends random selection with think time so every student prepares an answer.
